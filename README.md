### 👨‍💻 Executive Summary

Seasoned **Senior DevOps & Cloud Platform Engineer** with **13+ years of comprehensive enterprise IT experience**, including **5+ dedicated years architecting, automating, and operating modern Cloud & DevOps solutions**.

My career is anchored in deep, battle-tested foundations: **8 years of enterprise Systems & Infrastructure Administration** (bare-metal, virtualization, storage, complex hybrid networks, disaster recovery, and 99.99% SLAs) seamlessly scaled into **5+ years of cutting-edge Cloud Architecture, Infrastructure as Code (Terraform), Container Orchestration (Kubernetes/AKS), and Enterprise CI/CD Automation (Azure DevOps & GitHub Actions)**.

Because I understand how software interacts with hardware, kernels, hypervisors, and networks at the lowest levels, I build cloud platforms that are resilient, cost-optimized, and free of the fragile misconfigurations common in modern cloud environments.

- 🔭 **Current Focus**: Designing enterprise multi-region Azure Landing Zones, modular Terraform frameworks, and zero-trust GitOps pipelines.
- ⚙️ **Engineering Philosophy**: *"Reliability is not an afterthought — build immutable, automated, self-healing systems as code."*
- 🎯 **Career Objective**: Leading cloud transformations, platform engineering, and high-velocity delivery as a **Senior / Lead DevOps & Cloud Platform Engineer**.
- 💡 **Open For**: Senior DevOps Engineer, Lead Cloud Engineer, Platform Engineer, and Site Reliability (SRE) roles.
